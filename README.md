# Guru Pranesh — Profile Card Portfolio

A responsive, modern dark portfolio website built with plain HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Profile introduction, skills, education and experience
- GitHub profile links
- Edit profile modal (changes are saved in the current browser using localStorage)
- Print-friendly layout (use the browser's Print → Save as PDF option)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. Wait for the Pages deployment to finish. GitHub will show the published website URL in the Pages settings.

## Customise
Edit `index.html` for profile details and sections, `style.css` for appearance, and `script.js` for profile editing behaviour.

The Edit Profile form saves changes only in the browser where they are made. To update the public website for everyone, change the source files and commit them to GitHub.
